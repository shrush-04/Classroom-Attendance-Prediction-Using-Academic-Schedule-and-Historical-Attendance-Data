# Source Record Checklist

Use this checklist to verify that all source documents are officially authorized and correct before extracting lecture attendance statistics.

- [ ] **Department Master Timetable**
  - [ ] Issued and signed by the Head of Department (HOD) or Timetable Coordinator.
  - [ ] Reflected current swaps or adjustments made during the semester.
  - [ ] Checked against actual slot timings (e.g., 09:00 - 10:00).

- [ ] **Faculty Attendance Registers / Diaries**
  - [ ] Verified physically by the course instructor.
  - [ ] Confirms the aggregate count of present students matches the marks checked in the register grids.
  - [ ] Signed or initialed for each date of instruction.

- [ ] **Lab Registers / Practical Journals**
  - [ ] Captures lab batch attendance (e.g., Batch B1 and B2 counts are added to get the total class session present count).
  - [ ] Logged on the specific date and hour of the lab.

- [ ] **Academic Calendar**
  - [ ] Issued by the university or institution for the current academic session.
  - [ ] Confirms start and end dates of the semester.
  - [ ] Validates list of national, regional, and institutional holidays.

- [ ] **Examination Schedule**
  - [ ] Official notification of Continuous Internal Evaluation (CIE) / midterm exams.
  - [ ] Used to mark `Internal_Test_Week` as `1` for the dates corresponding to exams.

- [ ] **Department Attendance Sheets**
  - [ ] Verified monthly aggregate report submitted to the administration.
  - [ ] Used as a secondary source to cross-check student count totals.
